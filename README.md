## Что это

**Notion Auto Pay** — это локальный Go-сервер + React-веб-панель, который позволяет:

- **вести несколько аккаунтов Notion** в одном окне и переключаться между ними
- **чатиться с Notion AI** (все модели, включая Sonnet, по каждому аккаунту/пространству отдельно)
- **автоматически платить** подписку Notion AI по расписанию (auto-pay) серверным планировщиком
- **активировать free trial** без привязки карты
- **управлять рабочими пространствами**: создавать/удалять, подключать MCP-серверы, включать доп. токены
- **предоставлять OpenAI-совместимый API** (`/v1/chat/completions`), который принимают любые приложения, поддерживающие ChatGPT-протокол

Сервер запускается локально, все данные хранятся на вашем компьютере в папке `accounts/`.

## Быстрый старт

```
1. git clone https://github.com/Loki-Skylineop/Notion-Auto-Pay
2. cd Notion-Auto-Pay
3. Дважды кликнуть build.bat
```

При первом запуске `build.bat` автоматически:
1. устанавливает npm-зависимости (`web/node_modules`)
2. собирает React-фронтенд (`npm run build`)
3. копирует сборку в `internal/web/dist`
4. запускает Go-сервер на `http://localhost:8081`

Панель будет доступна по адресу: **http://localhost:8081/dashboard/**

> **Со второго запуска** `node_modules` уже есть — сборка запускается за ~5-10 секунд.

## build.bat и buildloki.bat

Проект идёт с двумя сценариями запуска:

### `build.bat` — обычный

Простой локальный запуск без лишнего:
- Без запроса прав администратора (UAC)
- Без правил брандмауэра
- Панель доступна только с текущего ПК

```bat
build.bat                        # собрать + запустить
build.bat exe                    # только собрать notion-auto-pay.exe
build.bat run                    # собрать + запустить
build.bat clean                  # удалить артефакты сборки
build.bat --password=МойПароль   # защитить панель паролем
```

### `buildloki.bat` — с LAN-доступом

Полный запуск с доступом из локальной сети (например, с телефона):
- Запрашивает права администратора (UAC) — для правила брандмауэра
- Создаёт временное правило брандмауэра для порта  8081 — удаляется при закрытии окна
- Печатает LAN-адрес вида `http://192.168.x.x:8081/dashboard/`
- Панель доступна с любого устройства в одной Wi-Fi сети

```bat
buildloki.bat                    # собрать + запустить с LAN-доступом
buildloki.bat --password=МойПароль  # + защита паролем
```

> **Итог:**  
> `build.bat` — для работы за (пассивного) пользования с ПК.  
> `buildloki.bat` — для доступа с телефона/планшета в локальной сети.

## Пароль на панель

По умолчанию панель открыта без пароля. Способы задать пароль:

**1. Через аргумент build.bat:**
```bat
build.bat --password=СекретныйПароль
```

**2. Через переменную окружения (до запуска):**
```bat
set DASHBOARD_PASSWORD=СекретныйПароль
build.bat
```

**3. Через скомпилированный .exe:**
```bat
build.bat exe
notion-auto-pay.exe --password=СекретныйПароль
```

**Приоритет пароля:** `--password` (флаг) > `DASHBOARD_PASSWORD` (окружение) > `admin_password` (в `config.yaml`).

`--no-password` (передаётся build.bat автоматически) — отменяет даже сохранённый пароль в `config.yaml`, так что забытый пароль некогда не заблокирует вход.

Pri включённом пароле автоматически включается rate limit: не более 10 попыток входа за 15 минут.

## Конфигурация (config.yaml)

Файл `config.yaml` лежит в корне проекта. Если его нет — создаётся автоматически при первом запуске.

Пример полной конфигурации (`example.config.yaml`):

```yaml
server:
  port: "8081"               # Порт сервера. По умолчанию 8081
  api_key: "sk-..."          # API-ключ для /v1/chat/completions. Можно любой
  admin_password: ""         # Пароль панели. Лучше задавать через --password

stripe:
  key: "sk_live_..."         # Stripe Secret Key — нужен для оплаты/автоплатёжа
```

Ключи `api_key` и `stripe.key` сохраняются только локально и **никогда не передаются** в Notion или куда-либо.

### Stripe Key

Для оплаты и автоплатёжа нужен **Stripe Secret Key** (`sk_live_...`).
Оплата происходит через серверную сторону (не через браузер), поэтому сключаемся только `sk_live_`, а не publishable key.

Free trial работает без Stripe Key.

## Аккаунты (accounts/)

Папка `accounts/` хранит данные всех добавленных аккаунтов:

```
accounts/
  grisha@example.com.json        # данные аккаунта (token_v2, user_id, ...)
  another@example.com.json
  .autopay.json                  # конфиг автоплатёжа (заполняется автоматически)
```

### Как добавить аккаунт

1. Откройте панель и нажмите кнопку **«Добавить аккаунт»** в верхнем правом углу
2. Введите `token_v2` — токен сессии вашего аккаунта Notion
3. Сервер автоматически найдёт все рабочие пространства (достаточно Plus/Business)

### Где взять token_v2

1. Откройте [notion.so](https://notion.so) в браузере
2. Откройте DevTools (F12) → **Application** → **Cookies** → `notion.so`
3. Найдите `token_v2` и скопируйте значение

Токен сделает жизнь **несколько месяцев** (до реального выхода). Если вышел — просто добавьте аккаунт заново.

## Функции панели

Панель состоит из двух вкладок: **Чат** и **Оплата**.

---

### Чат

Вкладка **«Чат»** — полноценный клиент для работы с Notion AI:

- **Множество аккаунтов** — выбирайте аккаунт и рабочее пространство из выпадающего списка
- **Модели** — выбор модели (Claude Sonnet, Haiku, GPT-4o и др.)
- **Размышление** (Reasoning effort) — настройка глубины размышления для моделей с extended thinking
- **История чатов** — сбоковая панель со всеми тредами аккаунта
- **Параллельные ходы** — отправляйте сообщение в один чат, не дожидаясь ответа в другом
- **Редактирование сообщений** — измените отправленное сообщение, агент перезапустит ход
- **Прикреплённые файлы** — прикрепляйте документы к сообщению
- **Стриминг** — ответ появляется в реальном времени с live шагами (tool calls, reasoning)
- **Доп. токены (ДОП)** — быстрое включение «доп. кредитов» перед отправкой; выключается автоматически, как только агент начал отвечать
- **Агенты** — выбор AI-агента для пространства
- **Стоп** — остановка идущего хода по кнопке ⏹
- **Частицы** — анимация частиц на фоне (настраиваемая)

---

### Оплата и автоплатёж

Вкладка **«Оплата»** отображает все аккаунты и их рабочие пространства с информацией о плане и статусе.

#### Ручная оплата

Для каждого пространства доступны кнопки:
- **Trial** — активировать free trial без привязки карты
- **Оплатить** — оплатить подписку сохранённой картой

#### Автоплатёж

Серверный планировщик, который работает **даже когда окно закрыто**:

- Выбираете, какие пространства включить в автоплатёж
- Задаёте интервал проверки (по умолчанию каждые 24 часа)
- Сервер сам платит за сутки до истечения (Stripe)
- Можно задать разный план (тариф) для каждого пространства отдельно
- **Нажать «Запустить»** — проверить все пространства вручную сейчас

---

### Рабочие пространства (Workspaces)

Для каждого аккаунта в панели видны:

- **План, дата продления, остаток AI-токенов**
- **Создать новые workspace** — булк-создание под аккаунтом
- **Удалить workspace** — бесповоротная операция, подтверждается диалогом
- **Обновить** (кнопка в верхнем правом углу) — перечитать все аккаунты с Notion заново

---

### MCP-серверы

Каждое пространство может иметь подключённый MCP (Модель контекстных протоколов) сервер, который расширяет возможности агента.

Через панель можно:
- **Подключить** MCP-сервер по URL
- **Отключить** MCP-сервер
- Указать заголовок аутентификации (если MCP-сервер требует API-ключ)

---

### Доп. токены (Overage)

Бейдж **«ДОП»** возле названия пространства включает режим «использовать дополнительные кредиты» на стороне Notion (когда в пространстве закончились AI-токены). Выключается автоматически после того, как агент начал отвечать.

## OpenAI-совместимый API

Сервер предоставляет полностью совместимый с OpenAI эндпойнт `/v1/chat/completions`.
Подходит для любых приложений: **Open WebUI, LibreChat, Cursor, Continue.dev** и др.

**Параметры:**

```
Base URL:  http://localhost:8081
API Key:   значение api_key из config.yaml
Model:     любой (notion-manager использует дефолтную модель пространства)
```

**Пример запроса (`curl`):**

```bash
curl http://localhost:8081/v1/chat/completions \
  -H "Authorization: Bearer sk-...ваш-api-key..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "notion-ai",
    "messages": [{"role": "user", "content": "Привет!"}]
  }'
```

**Streaming:**
```bash
curl http://localhost:8081/v1/chat/completions \
  -H "Authorization: Bearer sk-..." \
  -H "Content-Type: application/json" \
  -d '{"model": "notion-ai", "stream": true, "messages": [{"role": "user", "content": "Hello"}]}'
```

> Для работы API необходим аккаунт с активным планом Notion AI в базе данных.

## HTTP API эндпойнты

Все `/admin/*` маршруты защищены тем же паролем/API-ключом, что и веб-панель.

### OpenAI API

| Метод | Маршрут | Описание |
|---|---|---|
| POST | `/v1/chat/completions` | Отправка сообщения через Notion AI (OpenAI-формат, streaming поддерживается) |

### Аккаунты и пространства

| Метод | Маршрут | Описание |
|---|---|---|
| POST | `/admin/discover` | Обнаружение workspace'ов по token_v2 |
| GET | `/admin/workspaces` | Полный список всех аккаунтов и их workspace'ов |
| POST | `/admin/workspaces/create` | Булк-создание новых workspace'ов со случайными именами |
| POST | `/admin/workspaces/delete` | Удаление workspace'ов (безвозвратно) |

| Метод | Маршрут | Описание |
|---|---|---|
| POST | `/admin/subscribe` | Оплата подписки сохранённой картой |

| Метод | Маршрут | Описание |
|---|---|---|
| GET | `/admin/autopay` | Получить конфиг автоплатёжа |

| POST | `/admin/autopay/run` | Запустить проверку автоплатёжа вручную |

| POST | `/admin/chat/stream` | Отправить сообщение (стриминг с live-шагами) |

## Частые вопросы

### Почему аккаунт не появляется в списке после добавления?

Workspace отфильтровывается если у него бесплатный (Free) план без автоплатёжа. Добавьте пространство в автоплатёж или воспользуйтесь trial.

### Почему build.bat запускается долго?

При первом запуске `npm install` скачивает пакеты (~300 MB). Со второго запуска `node_modules` уже есть — сборка занимает 5-10 секунд.

### Порт 8081 занят. Как изменить?

Добавьте в `config.yaml`:
```yaml
server:
  port: "9090"
```

### Токен перестал работать

Повторно добавьте аккаунт: нажмите кнопку с плюсом «Добавить аккаунт» и введите новый `token_v2` для того же аккаунта. Старый файл заменится.

### Чат не работает / ошибка 403

Workspace должен иметь активный план Notion AI (Plus/Business). Триал или подписка должны быть активны.

### Как собрать только .exe без запуска?

```bat
build.bat exe
```

Файл `notion-auto-pay.exe` появится в корне проекта. Запуск:
```bat
notion-auto-pay.exe --no-password
notion-auto-pay.exe --password=МойПароль
```

### Как удалить аккаунт?

Через UI: вкладка «Оплата» → нажать иконку корзины рядом с аккаунтом → подтвердить.
Или вручную удалить JSON-файл из `accounts/`.
